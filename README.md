# Mini Calculator (Python)

This is a simple command-line based calculator made using Python.  
The program allows the user to perform multiple arithmetic operations and continues running until the user chooses to exit.

---

## 🔢 Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`) — includes divide-by-zero safety check
- Power (`^`) → num1 raised to num2
- Percentage (`%`) → (num1 * num2) / 100
- Modulus (`%%`) → num1 % num2

The program runs in a **loop**, so you can perform multiple calculations without restarting it.

---

## 🛠️ How It Works

1. User enters the first number  
2. User chooses an operator  
3. User enters the second number  
4. Program performs the calculation and prints the result  
5. Asks if user wants to continue
